# Materiais_Fornecedores_Homologados

Lista de relacionamento entre materiais oficiais e fornecedores homologados.

## Arquivos

- `materiais-fornecedores-homologados.md` — documentação funcional.
- `materiais-fornecedores-homologados.schema.json` — snapshot do schema real no SharePoint.

## Papel no sistema

Representa a relação N:N:

Material Oficial ↔ Fornecedor Homologado

Um material pode possuir vários fornecedores homologados e um fornecedor pode estar homologado para vários materiais.

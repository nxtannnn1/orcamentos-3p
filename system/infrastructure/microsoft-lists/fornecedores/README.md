# Fornecedores

Cadastro mestre de fornecedores do Sistema 3P.

## Arquivos

- `fornecedores.md` — documentação funcional.
- `fornecedores.schema.json` — snapshot do schema real no SharePoint.

## Papel no sistema

Centraliza a identificação dos fornecedores e fornece uma referência única para relacionamentos futuros e controle de duplicidade.

## Relacionamentos principais

- Materiais_Fornecedores_Homologados
- Orçamentos e histórico de preços, conforme evolução do sistema.

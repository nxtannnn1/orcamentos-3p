# Arquivos_Processados

Lista técnica de controle do processamento de arquivos.

## Arquivos

- `arquivos-processados.md` — documentação funcional.
- `arquivos-processados.schema.json` — snapshot do schema real no SharePoint.

## Papel no sistema

Controla quais arquivos já foram identificados e processados pelas automações, incluindo status, código do orçamento, erros e identificação física do arquivo.

## Campo importante

`DriveFileId` é utilizado para identificação do arquivo de origem e controle de processamento.

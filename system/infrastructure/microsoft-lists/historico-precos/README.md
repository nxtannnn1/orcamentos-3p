# Historico_Precos

Base histórica de preços validados do Sistema 3P.

## Arquivos

- `historico-precos.md` — documentação funcional.
- `historico-precos.schema.json` — snapshot do schema real no SharePoint.

## Papel no sistema

Armazena preços provenientes de itens validados, preservando referências ao material, orçamento e item de origem.

É a base para consultas, comparação de preços e indicadores.

# Itens_Importados

Lista responsável pelos itens extraídos dos orçamentos.

## Arquivos

- `itens-importados.md` — documentação funcional.
- `itens-importados.schema.json` — snapshot do schema real no SharePoint.

## Papel no sistema

Armazena os dados extraídos de cada item antes e durante o processo de validação e associação ao material oficial.

## Relacionamentos principais

- Orcamentos
- Materiais_Oficiais
- Historico_Precos
- Tributos_Itens_Orcamentos

## Manutenção

Alterações estruturais devem ser avaliadas quanto ao impacto no processamento do n8n, validação e envio ao histórico.

# SharePoint

Este diretório é reservado para documentação técnica e referências sanitizadas relacionadas à integração do Sistema de Orçamentos 3P com SharePoint.

## Política de versionamento

Artefatos operacionais do ambiente SharePoint não devem ser armazenados neste diretório.

Não versionar:

- credenciais ou tokens;
- tenant IDs;
- IDs e URLs sensíveis de sites ou listas;
- exports operacionais;
- dados pessoais;
- dados comerciais reais;
- arquivos contendo informações internas do ambiente Microsoft 365 da 3P.

## Schemas

A documentação estrutural sanitizada das listas utilizadas pelo sistema é mantida em:

`system/infrastructure/microsoft-lists/`

Este diretório deve permanecer restrito a documentação segura e artefatos explicitamente sanitizados.
